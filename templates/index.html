How the parser works

1
Text Extraction & Cleaning

Extracts raw text streams using pdfplumber and normalizes whitespace, bullets, and line boundaries.

2
Section Identification

Identifies standard headings (Education, Experience, Skills, Projects, Certifications) using an alias dictionary.

3
Deterministic Extraction

Applies regex for contacts, controlled vocabulary for skills, date ranges, and returns structured data with validation.
